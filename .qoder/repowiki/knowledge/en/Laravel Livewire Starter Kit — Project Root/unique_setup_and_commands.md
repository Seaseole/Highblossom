Composer scripts provide `composer setup` (install deps, copy `.env.example`, generate key, migrate, npm install/build), `composer dev` (concurrently runs server, queue listener, pail logs, and vite dev), `composer lint` / `lint:check` via Pint, and `composer test` (clear config → lint → phpunit). Docker compose starts via `docker compose up --build` from the EnvKit Packager template.
