This leaf module is the project root manifest layer for a Laravel application (laravel/livewire-starter-kit). It defines three build/execution surfaces:
- Backend: `composer.json` pins Laravel ^13.0 with Livewire ^4.3, Fortify, Sanctum, Passkeys, Spatie Permissions, AdminLTE, Image Intervention, Resend, S3/Flysystem, ffmpeg, plus dev tooling (Pint, Pail, Truss, Query Detector, Brain). A local path repository at `packages/ContentBlocks` is symlinked in as a dependency.
- Frontend: `package.json` + `vite.config.js` declare Vite 8 + Tailwind CSS v4 as the asset pipeline, with multiple entry points split by audience: public site (`app.css`, `site-booking.js`, `site-alpine.js`), auth views (`auth.css`, `auth-alpine.js`), and the admin panel (`admin.css`, `admin.js`).
- Containers: multi-stage `Dockerfile` builds vendor assets via Composer 2 and Node 22 Alpine, then ships an `php:8.4-fpm-alpine` image running nginx + php-fpm under supervisord with queue worker and scheduler. `docker-compose.yml` adds a MySQL 8.4 service on port 8080.
- Conventions: `pint.json` enforces the Laravel preset with vertical-aligned PHPDoc; `CONVENTIONS.md` (auto-generated by Laravel Brain) documents the Route → Middleware → Controller → Service → Model flow across 118 routes, 117 actions, 159 services, 23 models, and 3 commands.
